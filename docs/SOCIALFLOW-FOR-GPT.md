# SocialFlow: מה זה, ואיך זה קשור לרילסי ולדנה (עדכון 3.10.2026)

## מה זה SocialFlow
**SocialFlow הוא מוצר SaaS נפרד של יעקב לאוטומציית תגובות באינסטגרם ובפייסבוק**, בסגנון ManyChat.
- **אתר:** isocialflow.com, ב-9 שפות.
- **קוד:** ריפו נפרד ופרויקט Vercel נפרד, תחת חשבון gkobzafrani.
- **מסד נתונים:** Supabase ייעודי (פרנקפורט).

**מה הוא עושה:**
1. **תגובה עם מילת מפתח:** מישהו מגיב על פוסט או ריל עם מילת מפתח (למשל "מדריך"). המערכת עונה לו בפומבי מתחת לתגובה, ושולחת לו **הודעה פרטית** עם קישור. המגיב נשמר כליד.
2. **מענה בהודעות:** אוטומציות לתשובות לסטורי ולהודעות נכנסות, ותיבת הודעות לניהול שיחות.
3. **MCP:** אפשר לנהל את הכל מתוך Claude, ChatGPT ו-Grok Bot.
4. **יומן:** כל פעולה נרשמת, עם מדדים: תגובות, הודעות שנשלחו ולידים.

**איך זה עובד טכנית:**
- סריקת תגובות כל 2 דקות (Vercel Cron), דרך Graph API של Meta עם הטוקנים של העמודים.
- מטא מאפשרת **הודעה פרטית אחת לכל תגובה**, ואין שידור יזום לרשימות.

## מצב עסקי ומוצרי
- **עדיפות:** לפי ההחלטה מ-25.9, SocialFlow במצב **תחזוקה**. הפוקוס הוא tzedek.me ורילסי.
- **מחירים:** חינם, Creator 49 ₪, Pro 99 ₪ (כולל MCP ופרסום), Agency 249 ₪. המדידה לפי הודעות פרטיות בחודש.
- **בטא סגורה:** האפליקציה הציבורית של מטא עדיין לא אושרה. מצטרפים ידנית כבודקים.
- **תוכנית שותפים:** 50% מכל תשלום ל-12 חודשים, שיוך לפי הנגיעה הראשונה.
- **משתמש פעיל לדוגמה:** טוליק. קיבל השבוע 20 חשבונות נוספים.

## מה נבנה ב-SocialFlow היום (3.10)
1. **התראת ניתוק:**
   - כשמטא מנתקים חשבון (שינוי סיסמה, בדיקת אבטחה), מופיע באנר "חבר מחדש" בכל המסכים.
   - הלקוח מקבל מייל ווואטסאפ (פעם אחת, ותזכורת אחרי 24 שעות), ויעקב מקבל התראה בוואטסאפ.
   - התחברות מחדש מנקה את ההתראה.
2. **תוכנית שותפים בתוך האפליקציה:** מסך "שותפים" עם הצטרפות עצמית, קישור אישי עם העתקה ושיתוף בוואטסאפ, קליקים, נרשמים ועמלות.
3. **Grok Bot במסך ה-MCP:** הוראות חיבור ב-3 שלבים, עם כתובת וכותרת הרשאה להעתקה.
4. **תיקון זיהוי:** ניתוק באוטומציות של פוסט ספציפי לא זוהה, ועכשיו כן.

## הקשר לרילסי
- **רילסי מייצרת את התוכן, ו-SocialFlow הופך אותו ללידים.** כל ריל או מודעה שעולים מקבלים אוטומציה ב-SocialFlow: "הגיבו X וקבלו Y בהודעה".
- **כלל קבוע:** מודעה היא פוסט אינסטגרם נפרד. לכל מודעה חדשה צריך ליצור אוטומציה נפרדת על ה-media id שלה.
- **דוגמה מהיום:** ריל עדכון Claude Code נוצר במנוע של רילסי ופורסם, ועליו אוטומציה למילה "מוד" ששולחת את המדריך. שתי תגובות קיבלו את ההודעה תוך כדקה.
- **לולאת הלמידה:** המספרים מ-SocialFlow (תגובות, הודעות, לידים לפי פוסט ומילת מפתח) מזינים את ההצעות של רילסי: איזה סוג ריל ואיזו קריאה לפעולה מביאים לידים.
- **בעתיד:** SocialFlow הוא ערוץ ההפצה וההמרה הטבעי ללקוחות רילסי, בתור חבילה משותפת של "תוכן ולידים".

## הקשר לדנה
- **דנה היא סוכנת הוואטסאפ** (Green API, המספר של רילסי). SocialFlow עובד באינסטגרם ובפייסבוק. שני ערוצים שונים, שמשלימים זה את זה.
- **איך הם מתחברים:**
  - ההודעה הפרטית מ-SocialFlow שולחת את הליד לקישור, למשל /first או /magic של רילסי, או מדריך.
  - כשהליד הופך להזמנה ברילסי, **דנה לוקחת אותו מקצה לקצה בוואטסאפ**: סטטוס, בחירות, מסירה ופידבק.
- **אותה תשתית:** התראות הניתוק של SocialFlow יוצאות דרך אותו קו Green API, ומאותם כללי זהירות: בלי הודעה יזומה ללקוח בלי נוסח מאושר.
- **כלל משותף:** הודעות ללקוחות רק בנוסח מאושר. מה שיעקב מתקן נכנס ללמידה: אצל דנה בקובץ `DANA_BRAIN.md`, ובשכבת הלמידה (`ll.corrections`).

## מספרים ונקודות חשובות להבנה
- SocialFlow ורילסי הם **מוצרים נפרדים בקוד ובתשתית**, אבל באותה משפחה עסקית, ומשלימים זה את זה בשיווק.
- **הסיכון המרכזי ב-SocialFlow:** תלות במטא, גם באישור האפליקציה וגם בטוקנים שמתנתקים. לכן נבנו היום התראות הניתוק.
- **הצעד הבא:** להשלים את ההקלטה ולהגיש מחדש. אחרי אישור, כל אחד יוכל להתחבר בלי הוספה ידנית כבודק.
